📘 Как это менять — подробная инструкция

Коротко про два поля:

  • Ссылка-приглашение — это то, что пользователь видит и по чему заходит (кнопка «🔒 Приватка» / «💬 Чат»). Её можно менять сколько угодно.
  • Chat ID — внутренний номер канала/чата (вида -100…), по нему бот сам впускает и удаляет участников. Его нужно менять только если вы подключаете совсем другой канал/чат. Если это тот же канал/чат, а вы просто обновили ссылку-приглашение — Chat ID не трогайте.

Ситуация 1. Поменять только ссылку (тот же канал/чат) — самое частое

  1. В Telegram откройте нужный канал/чат → Управление → Пригласительные ссылки → создайте новую ссылку (или скопируйте существующую вида https://t.me/+…).
  2. Вставьте её сюда в поле «Ссылка-приглашение» нужного ресурса.
  3. Поле Chat ID оставьте как есть.
  4. Нажмите «Сохранить». Готово — новая ссылка сразу заработает в боте.

Ситуация 2. Подключить другой канал/чат

Тут нужно и новую ссылку, и новый Chat ID, и добавить бота админом:

  1. Добавьте бота @themainschool_bot в новый канал/чат администратором с правами «Пригласительные ссылки» и «Блокировать пользователей» (без этого авто-доступ не работает).
  2. Возьмите ссылку-приглашение нового канала/чата (как в Ситуации 1).
  3. Узнайте Chat ID нового канала/чата (см. ниже «Как узнать Chat ID»).
  4. Впишите сюда новую ссылку и новый Chat ID → «Сохранить».

Как узнать Chat ID

Два простых способа (числа для канала/супергруппы начинаются с -100):

  • Через web.telegram.org: откройте канал/чат на web.telegram.org (версия A) — в адресной строке после # будет число вида -1001234567890. Это и есть Chat ID.
  • Через бота-помощника: напишите любое сообщение в канале/чате, перешлите его боту @getidsbot — он ответит Chat ID: -100….
⚠️ Важно
  • Не путайте канал и чат — у каждого свой Chat ID и своя ссылка. Заполняйте в соответствующей карточке.
  • Меняете сам канал/чат — обязательно сначала добавьте бота админом туда, иначе он не сможет впускать/удалять.
  • Если оставить оба поля пустыми — ресурс просто не показывается в боте (кнопки не будет).
  • «Форум» сейчас не используется — оставьте его пустым, если отдельного форума нет.
